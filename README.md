Salary Prediction Using Machine Learning

Project Overview

This project predicts employee salaries based on years of work experience using Machine Learning.

A Linear Regression algorithm is trained on a salary dataset to identify the relationship between experience and salary.

Objective

To develop a Machine Learning model that estimates salaries based on an employee's years of experience.

Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Streamlit
- Jupyter Notebook

Machine Learning Algorithm

Linear Regression

The model learns the relationship between:

- Independent Variable: Years of Experience
- Dependent Variable: Salary

Model Evaluation

- R² Score: 92.49%
- MAE: 5,146.89
- RMSE: 6,256.13
- MAPE: 6.05%

Streamlit Application

The project includes an interactive Streamlit frontend where users can:

- Enter years of experience.
- Predict their estimated salary.
- View predicted salary results.
- Visualize the relationship between experience and predicted salary.

How to Run

1. Clone this repository.
2. Install dependencies:

pip install -r requirements.txt

3. Run the Streamlit application:

streamlit run salary.py
